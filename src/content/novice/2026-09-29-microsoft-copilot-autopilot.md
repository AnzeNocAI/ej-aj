Microsoft je 25. septembra predstavil prenovljen Copilot za delo. Po novem ga sestavljajo trije deli: Home, Code in Autopilot. Za slovenska podjetja, ki delajo v Microsoft 365, je to napoved, ne nekaj, kar lahko vklopijo jutri: vsi trije deli bodo najprej na voljo v zgodnjem dostopu oziroma predogledu.

> **Na kratko:** Autopilot je agent, ki mu daste ime, vlogo in cilj, nato pa sam dela naprej, tudi ko vas ni za računalnikom. Preden ga boste lahko uporabili, se splača premisliti, katero ponavljajoče se opravilo bi mu dali in kaj bi smel narediti brez vaše potrditve.

## Home: klepet, Cowork in Office na enem mestu

Home je nova vstopna točka v Copilot. Združuje klepet in Cowork, torej hitre odgovore in naloge, ki jih Copilot opravi namesto vas. Word, Excel in PowerPoint so vgrajeni neposredno v Copilot, zato lahko dokument, preglednico ali predstavitev izdelate brez preklapljanja med aplikacijami.

## Code: majhne aplikacije brez programerja

Code je namenjen vsem, ne le programerjem. Z opisom v navadnem jeziku lahko po navedbah Microsofta izdelate majhne namenske rešitve: pripomoček, nadzorno ploščo, sledilnik ali interno aplikacijo v oblaku. Poganja ga ista tehnologija kot GitHub Copilot, rešitve pa tečejo v zaprtem okolju znotraj najemnika (tenanta) podjetja.

## Autopilot: agent kot sodelavec

Autopilot se je prej imenoval Scout. Microsoft ga opisuje kot digitalnega sodelavca: uporabnik mu določi ime, vlogo in cilj, agent pa ima nato svojo identiteto, spomin in delovni prostor. Živi v najemniku podjetja, v Teams, Outlooku in kanalih pa ga omenite z @, kot bi sodelavca. Spremlja lahko kanale, sledi pogovorom in opravlja ponavljajoče se naloge. Microsoftov primer je celoten postopek pregleda dobaviteljev: agent pripravi urnik in načrt, nato sam vodi pripravo, sestanke in nadaljnje korake.

## Kdaj in koliko

Home in Code bodo po Microsoftovih besedah v prihodnjih tednih postopoma prišli v program Frontier, Microsoftov program zgodnjega dostopa. Autopilot se konec septembra razširi v zasebni predogled. Code bo naročnikom paketov Microsoft 365 Premium in Pro na voljo v predogledu kasneje letos. Microsoft ni objavil posebnih datumov ali jezikov za Evropo.

Spremenil se je tudi način plačila. Vsakdanja raba (klepet, Office, izbira modela) ostaja v fiksni licenci na uporabnika, zahtevnejše agentno delo (Cowork, Code, Autopilot) pa se plača po porabi. Autopilot po Microsoftovih besedah deluje z dovoljenji, revizijsko sledjo in upravljanjem, porabo pa skrbniki omejijo s pravili, stroške spremljajo v Agent 365.

## Kaj pripraviti že zdaj

Stalni agent je najbolj uporaben pri opravilu, ki se ponavlja in ima jasne korake. Dobra vaja za ekipo, še preden Autopilot pride: vsak zapiše eno tako opravilo in ob njem tri stvari. Do katerih podatkov in aplikacij bi agent moral imeti dostop. Katera dejanja bi smel narediti sam in katera šele po človeški potrditvi (pošiljanje navzven, plačila, brisanje). Kdo in kako pogosto bo pregledal, kaj je agent naredil.

**Kaj to pomeni za vas:** plačilo po porabi pomeni, da strošek agentov ne bo več fiksen na sedež, zato bo treba porabo spremljati.
